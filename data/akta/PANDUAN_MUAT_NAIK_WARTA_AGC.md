## 2. Dua Cara Memuat Naik & Mengindeks PDF Warta

### Cara A: Melalui Antaramuka Web ("Direktori Akta" -> Tab "Pustaka Akta & Semakan Kesalahan")
1. Log masuk menggunakan akaun Pentadbir Pembangun (`zero4eleven@gmail.com`).
2. Buka tab **Direktori Akta** di bar navigasi atas, kemudian pilih sub-tab **4. Pustaka Akta & Admin Warta**.
3. Pilih kod `statute_id` (atau biarkan sistem mengesan secara automatik daripada nama fail seperti `AKTA_852.pdf`).
4. Muat naik fail PDF Warta Kerajaan Rasmi dan klik **Hurai & Indeks PDF Warta**.
5. Semak **Laporan Liputan 100%** (bilangan seksyen diindeks vs bilangan seksyen dalam PDF, serta senarai kesalahan baharu berstatus `DRAFT_PENDING_REVIEW`).
6. Klik **Sahkan Warta (`VERIFIED_AGC`)** selepas mengesahkan ketepatan ekstrak.

### Cara B: Melalui Skrip CLI (`scripts/ingest-statute.ts` atau `scripts/ingest_statute.py`)

```bash
# Menggunakan Python CLI
python3 scripts/ingest_statute.py --file data/akta/AKTA_852.pdf --statute-id AKTA_852

# Atau menggunakan TypeScript / Node CLI
npx tsx scripts/ingest-statute.ts --file data/akta/AKTA_852.pdf --statute-id AKTA_852

# Sahkan terus sebagai VERIFIED_AGC semasa muat naik CLI (pilihan)
python3 scripts/ingest_statute.py --file data/akta/PPKM_2009.pdf --statute-id PPKM_2009 --verify
```

## 3. Kesan Automatik Selepas Muat Naik PDF Warta Baharu
1. **Hash SHA-256 (`source_pdf_hash`)** direkodkan ke dalam `statutes_registry`.
2. **Pemotongan Seksyen Deterministik (Bukan LLM):** Setiap `Bahagian`, `Seksyen X.`, `Peraturan X.`, `(1)`, `(2)` dan `Jadual` disimpan 100% verbatim ke dalam `statute_sections_verbatim`.
3. **Imbasan Kesalahan Seksyen-demi-Seksyen:** Setiap peruntukan yang mengandungi kata kunci kesalahan (`"melakukan suatu kesalahan"`, `"apabila disabitkan"`, `"boleh didenda"`, `"dilarang"`, `"tidak boleh"`) dipetakan ke `master_offences_matrix` sebagai `DRAFT_PENDING_REVIEW`.
4. **Kawalan Cache Ketat (`statute_library_version`):** Versi pustaka akta dinaikkan secara automatik dan semua rekod cache lama bagi akta tersebut dalam `Koleksi Soalan & Jawapan Pakar` ditandakan sebagai `STALE` supaya jawapan lama tidak dipetik semula.
